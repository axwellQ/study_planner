# 🎓 Планировщик учёбы с уведомлениями в Telegram

Простое и удобное приложение для студентов: добавляй дедлайны, отмечай выполненные задания и получай **автоматические напоминания в Telegram**!

## ✨ Возможности

- 🖥️ **Графический интерфейс** (на Tkinter) для управления дедлайнами
- 👤 **Профиль пользователя** (имя + Telegram ID)
- 🔔 **Автоматическое уведомление в Telegram**:
  - за 7 дней до дедлайна
  - за 1 день до дедлайна
- 📲 **Просмотр задач в Telegram** — отправь боту команду `/tasks`
- ✅ Отметка заданий как выполненных
- 📅 Цветовая индикация:
  - 🔴 Просрочено
  - 🔥 Сегодня
  - ⚠️ Скоро (в ближайшие 7 дней)
  - 📅 В будущем
  - ✅ Выполнено
